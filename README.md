# EvoSDK → Sprinter

Порт **EvoSDK** — C-SDK для 8-битных Z80-машин **ZX Evolution / ATM Turbo** — на компьютер
**Sprinter** под управлением операционной системы **DSS**.

Цель проекта: игры и программы, написанные под EvoSDK (`game_xnx`, `robo`, `innsmouth`,
`example_*`, `empty_project`), должны собираться под Sprinter **без единой правки исходного
кода**, сохраняя при этом возможность сборки под исходный таргет ATM/Evo.

Девиз: **то же поведение, та же скорость, тот же объём — но на Sprinter.**

## 📖 Документация

**[Как написать игру на ZX Spectrum (Evo / Sprinter) с помощью EvoSDK](doc/evosdk-guide.md)**
— самодостаточное руководство для разработчика: от первого проекта до готовой игры
(концепции, ресурсы, графика, спрайты, звук, ввод, сборка, полный справочник API).

## Структура репозитория

| Каталог | Назначение |
|---------|-----------|
| `doc/` | документация (руководство разработчика) |
| `evosdk/` | оригинальный SDK (таргет ATM/Evo) — эталон API и архитектуры |
| `sprintersdk/` | порт под Sprinter (библиотеки, тулчейн ассетов на Python, загрузчик) |
| `empty_project/`, `example_*/` | скелет и демо-проекты |
| `game_xnx/`, `innsmouth/`, `robo/` | игры; собираются и под Evo, и под Sprinter |

## Сборка

Сборка идёт **из каталога проекта** через `make` (правила в `sprintersdk/sprinter.mk`):

```sh
cd robo
make          # собрать Sprinter EXE
make clean    # очистить
```

Подробности (тулчейн SDCC 2.9.0, контракт ресурсов, опции, форматы, лимиты) —
в [руководстве](doc/evosdk-guide.md), глава 16.
